# Prompting Manga

Public website for **Prompting Manga**. Issue 01 is five essays and a reading order called the prompting path.

**Live:** https://socalwearart-collab.github.io/prompting-manga-web/

Static site (HTML/CSS/JS) hosted with GitHub Pages. No build step.

## Local

Open `index.html`, or from this folder:

```
python -m http.server 8741
```
